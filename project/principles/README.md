# 원칙 (principles)

이 프로젝트에서 **실제로 손해를 보고 얻은** 규칙만 적습니다. 일반론은 안
적습니다 — 각 항목은 그것을 어겨서 무엇을 잃었는지를 같이 적어야 합니다.

`metrics/` 와 같은 규약: 번호를 매기고, 덮어쓰지 않고, 폐기하면 이유를 남깁니다.

| # | 원칙 | 어겨서 잃은 것 |
|---|---|---|
| [00](00_how_to_run.md) | **어떻게 실험하는가** — 파일·명령·기준·순서 | 순서를 기억에 맡겼다가 리포트에 그림이 조용히 빠짐 |
| [01](01_validate_before_measuring.md) | **측정하기 전에 검증하라** | 이틀에 결론 4건 철회. 넷 다 새 물리가 아니라 설정 오류 |

## 강제 장치

원칙은 지켜지지 않습니다. 검사하는 코드가 있어야 지켜집니다.

- `scripts/gate_sweep.py` — 검사 6 개. **실패하면 종료 코드 1**
- `scripts/build_all.sh` — 6 단계 고정 순서. 한 단계 실패하면 아래를 안 만듦
- `scripts/make_samples.py` — `SAMPLES.md` 를 측정값에서 생성. 행 없는 숫자는 못 들어감
- `scripts/lock.py`, `scripts/gate.py` — 기존 회귀 검사. 2026-08-12/13 이틀 동안 **한 번도 호출되지 않았음**
