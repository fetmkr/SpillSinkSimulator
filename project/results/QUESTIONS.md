## Q1. 평판이 6.12 % 라는 숫자는 어디서 나왔습니까 — 계산상 나올 수 없는 값입니다 `[확인]`

**질문.** "같은 도장을 칠한 평판이 6.12 % 를 되쏜다"가 이 프로젝트의 모든 배수
(28배, 30배, 29배)의 분모입니다. 그런데 그 숫자를 만든 측정 파일이 저장소
어디에도 없고, 코팅 모델로는 그 값이 나오지 않습니다. 근거 파일은 어디 있습니까?

**어디서 나온 질문인가.**
- `scripts/analyze_buildable.py:37` — `FLAT_COATING_WORST = 0.061218  # measured,
  same theta set and materials`. 하드코딩된 상수입니다.
- 저장소 전체에서 `6.1218 / 0.061218` 이 나오는 곳은 이 상수와, 그것을 그대로
  받아쓴 `NEXT.md:89`, `JOURNAL.md:50`, `report/2026-08-13/data.json:3`,
  `report/2026-08-13/report.html:128,501` 뿐입니다. **CSV·JSON·로그 어디에도
  평판 측정 행이 없습니다** `[확인 grep]`.

**내가 직접 확인한 것.** `blender_render.make_coating` 은
`ρ(θ) = body·(1−s·F(θ)) + s·F(θ)` (F = IOR 1.5 의 정확한 Fresnel) 입니다.
이 식으로 `results/fit_coating.json` 의 Cycles 측정값을 재현하면 **소수점 6자리까지
일치**합니다(0°: 0.010600 대 0.010600, 45°: 0.011215 대 0.011216). 즉 모델은
정확히 이해된 상태입니다. 그 모델로 평판을 계산하면:

| θ | 실제 사용 코팅 | d00 (순수 반사) | d76 | d100 (순수 확산) |
|---|---|---|---|---|
| 0 | 0.998 % | 0.998 % | 0.996 % | 0.998 % |
| 20 | 1.000 % | 1.005 % | 0.998 % | 0.998 % |
| **40** | **1.033 %** | **1.141 %** | 1.030 % | 0.998 % |

**θ ≤ 40°, 재질 3종 전체에서 평판의 최댓값은 1.141 % 입니다. 6.1218 % 가 아니라.
5.4 배 차이입니다.**

6.1218 % 가 나오려면 셋 중 하나여야 합니다 `[추측]`:
(a) d00 에서 **θ ≈ 74.6°** — 즉 패널과 다른 각도 집합으로 잰 것,
(b) 실제 코팅에서 **θ ≈ 89°**,
(c) 1.141 % + 0.0498 — 즉 창 안에 배경(world radiance 1.0)이나 0.05 대조판이
    약 5 % 섞여 들어간 것.
셋 다 "패널과 같은 조건(same footing)"이 아닙니다.

**나쁘게 풀리면 무엇이 바뀌나.** 전부입니다.
- `SAMPLES.md:34,47,71,94,123` 의 **28배 / 1/28** → **약 5.3배**
- `JOURNAL.md:50`, `NEXT.md:89`, `report.html` 의 **"구조 vs 평판 30배, 기하가
  결정적"** → 5배대. 그리고 5배대는 이 프로젝트가 이미 2026-08-12 에 스스로 계산한
  값입니다: `reference/SUMMARY.md:529–531` — *"our best shingle reads 0.00182
  against a flat plate of the same coating at 0.00998 — a factor of 0.18, i.e.
  5.5×"*. **어느 시점에 분모가 0.00998 에서 0.061218 로 바뀌었고, 그 변경을
  기록한 측정이 없습니다.**
- `JOURNAL.md:88` 의 "Kaster 는 0.65배인데 우리는 0.03배, 이 격차를 설명해야
  한다" 도 대부분 사라집니다. 1.141 % 를 분모로 쓰면 0.2145/1.141 = **0.19배**로,
  Kaster 의 0.65배와 3배 차이입니다. **즉 이 오류 하나가 "설명해야 할 격차"를
  만들어냈을 가능성이 큽니다.** 이것은 Q1이 맞다는 방증이기도 합니다.

**이걸 푸는 방법.** 평판 렌더를 5개 각도 × 3개 재질로 다시 돌려서 CSV 행으로
남기십시오. 한 번의 렌더입니다. 그리고 그 행이 없으면 배수를 쓰지 마십시오.

## Q2. 벌집은 "같은 도장"이 아닌데, 왜 같은 표에 있습니까 `[확인]`

**질문.** `SAMPLES.md:6-7` 이 대전제로 못 박습니다 — *"전부 같은 도장(same
coating), 같은 배치. 도장이 다르면 네 숫자를 비교할 수 없습니다."* 그런데
`SAMPLES.md:42` 의 시료 ②는 **흑색 아노다이징 알루미늄**이고, `:60` 은
아노다이징이 깊이까지 들어간다는 것을 ②의 **장점**으로 내세우며,
`SAMPLES.md:153` 은 "②는 잘라서 아노다이징이 50 mm 안까지 들어갔는지 확인"을
측정 항목으로 올립니다. **②는 도장한 것이 아니라 양극산화한 것입니다.**

**나쁘게 풀리면.** `reference/HONEYCOMB_SPECS.md:148–152` 이 이미 답을 써
놓았습니다 — *"Black anodised aluminium is a different and generally worse
absorber; Kaster models it at 5 % reflectance... **If the panel is anodised
aluminium rather than painted, every absolute number in this project is off by
roughly 5×**"*. 즉 ②의 0.2195 % 는 1 % 코팅을 가정한 값이고, 실물이 5 % 반사의
양극산화면 **1 % 대**가 나옵니다. 그러면 "②③④가 오차 안에서 동률"이라는 시연의
전제(`SAMPLES.md:127`)가 무너지고, 벌집만 5배 밝습니다.

**둘 중 하나를 골라야 합니다.** 양극산화 벌집을 사서 그대로 쓴다면 숫자를 다시
계산해야 하고 "같은 도장" 문장을 지워야 합니다. 같은 도장을 칠하겠다면
`:60` 의 "아노다이징이라 깊이까지 균일" 장점이 사라지고
`metrics/01_rho_dh.md:48-49` 의 미해결 항목(깊은 셀 바닥까지 도장이 닿는가)이
그대로 돌아옵니다. **지금 문서는 두 가지 이점을 동시에 주장하고 있습니다.**

## Q3. "오차 안에서 동률"은 코팅이 완전 확산일 때만 참입니다 `[확인]`

그것부터 확인하면 고니오미터 예약 없이 이 축이 절반은 닫힙니다.

**나쁘게 풀리면.** 지금은 파일 이름만 보고 "코팅은 검증됐다"고 믿게 되어

## Q7. 날 배열의 날은 0.1 mm 판이 아닙니다 — 뿌리가 0.9 mm 인 쐐기입니다 `[확인]`

**질문.** `SAMPLES.md:68,77` 은 공급사에게 *"두께 0.1 mm … 0.1 mm 판재를 레이저로
